## Project Overview

**TransiTalk** is an AI-powered multilingual language translation application developed using Flutter. The application enables users to translate text between multiple languages quickly and accurately using an AI-based translation API. It provides a simple, responsive, and user-friendly interface for seamless communication across different languages.

---

## Problem Statement

Language barriers often make communication difficult while traveling, studying, or collaborating with people from different regions.

TransiTalk addresses this challenge by providing instant multilingual translation through an intuitive mobile application powered by AI translation services.

## Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/transitalk-language-translator.git
```

### Navigate to the project

```bash
cd transitalk-language-translator
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```

---

## How It Works

1. Enter text into the application.
2. Select the source and target languages.
3. The AI translation API processes the request.
4. The translated text is displayed instantly.
